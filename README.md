# 网页与视频转 Markdown

一个注重隐私和本地处理的 Chrome Manifest V3 浏览器插件，用于将文章、网页和视频页面整理为结构清晰的 Markdown 文档。

它支持提取网页标题、作者、发布时间、正文、视频简介、章节和页面可访问字幕，并提供 Markdown 导出与“一图速览”功能。

## 安装

1. 下载或克隆本项目。
2. 打开 `chrome://extensions`，或在 Edge 中打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择项目根目录。

项目当前适合开发者模式下本地安装和测试。

## 使用

打开文章或视频页面，点击扩展图标即可提取当前内容。

- `下载 Markdown`：导出标题、来源、作者、时间、正文、章节和字幕。
- `一图速览`：生成适合快速浏览的本地 SVG 总览图。
- `生成 AI 摘要`：使用用户配置的 OpenAI 兼容 API 生成摘要。
- `后台管理设置`：配置 API、获取模型、测试连接和选择本地保存位置。

没有可访问字幕时，插件不会下载视频或音频，也不会自动进行语音转写。

## 本地与开源

网页提取、Markdown 生成、一图速览和文件下载均在浏览器本地运行。插件不提供后台批量抓取，不自动遍历网页，也不会绕过登录、验证码、付费墙、DRM 或平台访问限制。

AI 功能默认关闭。只有用户主动测试 API、获取模型或生成摘要时，相关请求才会发送到用户配置的接口。API Key 保存在浏览器本地，不会写入导出的 Markdown 文件。

选择“本地指定文件夹”后，浏览器会显示系统文件夹选择器。选定目录后，导出的 Markdown 和 SVG 会直接写入该目录；也可以切换到默认下载目录、每次询问或默认下载目录下的子目录。
